## Топ-3 риска, требующих раннего доказательства
1. **T1 — эквивалентность офлайна.** Закрывается первым майлстоуном: без неё вся система времени ненадёжна.
2. **T2 — детерминизм боя.** Закрывается golden-тестами до создания экрана боя.
3. **T3 — баланс.** Закрывается инструментами (симулятор, ускорение времени), а не угадыванием чисел. Инструменты строятся вместе с системами, а не в конце.
