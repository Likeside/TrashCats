# Trash Cats — Спецификация контента

> Статус: черновик GDD v0.1. Числовые параметры — в [PROGRESSION_AND_ECONOMY.md](PROGRESSION_AND_ECONOMY.md) и [COMBAT_DESIGN.md](COMBAT_DESIGN.md).
> **Обязательное** — нужно для проверки гипотезы прототипа. **Опциональное** — делается, если останется время; на гипотезу не влияет.
> Стиль арта не выбран (фаза F). Требования ниже не зависят от стиля.

## 1. Коты игрока (обязательное)

| Id | Имя | Склонность | Силуэт / отличия | Характер в анимациях |
|---|---|---|---|---|
| `cat_ryzhy` | Рыжий | Сила | Рыжий, широкие плечи, порванное ухо, шрам | Резкий, задиристый |
| `cat_shnyr` | Шнырь | Ловкость | Серый в полоску, тощий, длинный хвост, большие уши | Суетливый, пружинистый |
| `cat_ponchik` | Пончик | Крепость | Чёрно-белый, круглый, маленькая голова | Медленный, флегматичный |

Требование: коты различимы **по силуэту** на размере ~150 px в высоту (панель котов) и в чёрно-белой проверке.

Все три кота делят один риг/набор анимаций (одинаковый скелет или одинаковая раскадровка), различия — в спрайтах и пропорциях 🔶.

## 5. Объекты убежища (обязательное)

Каждый объект — 3 визуальных состояния (ур.0, ур.1, ур.2) + анимация «улучшено» (подпрыгнуть, пыль, искры).

| Id | Объект | Ур.0 | Ур.1 | Ур.2 |
|---|---|---|---|---|
| `obj_boxes` | Коробки | Одна мятая коробка | Две коробки + тряпка | Домик из коробок с подушкой |
| `obj_dumpster` | Мусорный бак | Ржавый бак | Бак с подпоркой-лестницей | Бак с самодельным краном-крюком |
| `obj_can` | Банка | Банка на верёвке | Две банки | Ведро-«груша» |
| `obj_mouse` | Мышь | Заводная мышь | Мышь на машинке | Две мыши / лазерная указка |
| `obj_wheel` | Колесо | Колесо из таза | Колесо из шины | Колесо от велосипеда с подсветкой |

Анимации объектов при использовании: банка качается, мышь бегает, колесо крутится, бак трясётся.

## 8. Сводка анимаций

### 8.1. Риг «Кот» (3 игрока + Сёмга + Адмирал) — обязательное

| Анимация | Где | Цикл | Приоритет |
|---|---|---|---|
| `idle` | Везде | ✔ | Обязательно |
| `walk` | Убежище | ✔ | Обязательно |
| `train_punch`, `train_chase`, `train_run` | Станции | ✔ | Обязательно |
| `dig` | Бак | ✔ | Обязательно |
| `carry` | Возврат с едой | ✔ | Опционально (можно `walk` + спрайт в зубах) |
| `sleep` | Коробки | ✔ | Обязательно |
| `eat` | Кормление | ✘ | Обязательно |
| `attack_light`, `attack_heavy` | Бой | ✘ | Обязательно |
| `buff`, `throw` | Бой | ✘ | Обязательно |
| `dodge` | Бой (промах по коту) | ✘ | Обязательно |
| `hit` | Бой | ✘ | Обязательно |
| `ko` | Бой | ✘ | Обязательно |
| `victory` | Конец боя | ✔ | Обязательно |
| `enter` | Выход на ринг | ✘ | Опционально (можно `walk`) |
| `bubble_*` | Пузыри потребностей | — | UI-элемент, не анимация рига |

### 8.2. Риги врагов (Крыса, Птица, Енот, Собака) — обязательный минимум
`idle`, `attack_light`, `attack_heavy`, `buff`/`throw` (если есть умение), `dodge`, `hit`, `ko`.

**Итого:** риг Кот — ~16 анимаций; 4 вражеских рига по ~7.

## 9. VFX (обязательное, если не указано иное)
- Всплывающие числа урона (обычный / крит-подобный крупный для Укуса).
- «Мимо!» над уклонившимся.
- Полосы-царапины, вспышка укуса, облачко пыли.
- Иконки баффов/дебаффов над полосой HP.
- Красная виньетка «Ярость!» (внезапная смерть).
- Пыль/искры при улучшении объекта.
- Всплывающие иконки ресурсов при завершении цикла.
- Конфетти/звёзды на победе (опционально).

## 10. SFX (обязательное — минимальный набор; музыка — опционально)

| Группа | Звуки |
|---|---|
| UI | Тап, открытие листа, недоступно, покупка, popup, тост |
| Убежище | Звон банки, писк мыши, скрип колеса, шорох в баке, храп, чавканье, мурлыканье при получении уровня |
| Бой | Свист удара, попадание (лёгкое/тяжёлое), промах, шипение, KO, победа, поражение, «Ярость!» |
| Музыка (опционально) | Петля убежища (спокойная), петля боя (драйвовая), финальный джингл |

## 11. Тексты и локализация 🔶
- Язык прототипа: **русский** (основной). Все строки — в таблице локализации, а не в коде, чтобы позже добавить английский.
- Объём ~150 строк: UI, названия, описания умений, онбординг, подсказки поражения.

## 12. Опциональный контент (вне обязательного скоупа)
- Отдельная иллюстрация карты района (вместо схемы с иконками).
- Уникальные анимации входа на ринг для каждого кота.
- Эмоции котов в убежище (зевок, умывание) в простое.
- Музыка.
- Уникальный риг для Адмирала (вместо рига «Кот»).
