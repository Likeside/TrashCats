# Арт-раунд 2 — финалист A (S4, комикс)

4 концепта в стиле, выбранном в раунде 1: бой, тренировки, карта, UI-кит. Модель `gpt-image-2`, качество `high`, по одной генерации без перегенераций (`Tools/art_concepts.py --round 2 --styles S4`), промпты — в `prompts.md`.

**Наблюдения**
- **Бой** (`combat_S4.png`): бойцы читаются за счёт контура и тёплого/холодного контраста; сцена перегружена деталями фона. Модель одела Рыжего в штаны и нарисовала очереди своих котов внизу — в игре коты без одежды, раскладка по UI_UX §8.
- **Тренировки** (`training_S4.png`): лучшие позы из всех концептов — хорошо ложатся в зацикленные анимации.
- **Карта** (`map_S4.png`): вертикальный путь и состояния узлов понятны; лишние элементы UI (жизни, магазин) — фантазия модели.
- **UI-кит** (`uikit_S4.png`): картон, скотч, крышки — цельно с миром; бары и иконки читаются.
- **Производственный риск:** штриховка и халфтон плохо переживают скелетную деформацию. Для анимации нужен упрощённый «производственный» вариант стиля (меньше штриховки на подвижных частях, халфтон — оверлеем). Фиксируется в Art Bible.
