# Арт-раунд 1 — слепое сравнение

10 концептов: 5 стилей × 2 сцены (линейка котов, экран убежища). Модель `gpt-image-2`, качество `high`, по одной генерации на (стиль × сцена), без перегенераций. Сгенерировано скриптом `Tools/art_round1.py`, точные промпты — в `prompts.md`.

**Как оценивать**
1. Открыть `blind/lineup_sheet.jpg` и `blind/hideout_sheet.jpg` (полноразмерные — `blind/<сцена>_<буква>.png`).
2. Оценить каждую букву по листу из `Docs/ArtDirection/ART_DIRECTION_BRIEF.md` §4.3 (читаемость при 25%, силуэты, понятность сцены, юмор, реалистичность производства, единство с UI, «хочу играть»).
3. Только после оценки открыть `REVEAL.md`.

**Известные особенности генерации (одинаковы для всех стилей)**
- В убежище модель добавила четвёртого спящего кота в коробках (промпт не уточнял, кто спит).
- Надписи и числа в UI — случайные, не оцениваются.
- «Пиксель-арт» у модели не на строгой пиксельной сетке; в производстве он выглядел бы чище и стоил бы дороже в анимации.
