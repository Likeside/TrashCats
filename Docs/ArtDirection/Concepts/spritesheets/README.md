# Пилот спрайтшитов (Рыжий)

Цель: проверить, можно ли получать короткие покадровые анимации через `gpt-image-2` (edits от референса).

## Как сделано
1. `ref_ryzhy.png` — Рыжий, вырезанный из выбранного концепта (`round1/blind/lineup_A.png`).
2. `Tools/art_spritesheet.py <ref> <out> idle punch bite` — 4 кадра в ряд на зелёном хромакее (прозрачный фон модель не поддерживает).
3. `Tools/sprite_process.py <sheet> <out> --frames 4` — удаление хромакея с подавлением зелёной каймы, поиск кадров как отдельных фигур (кадры могут перекрываться по X), выравнивание по общей линии земли (прыжки сохраняют высоту), ячейки одного размера. Нужен `numpy` + `Pillow`.
4. `ref_ryzhy_idle.png` — кадр idle как референс для следующих клипов → `ryzhy_punch_v2.png`.

## Результаты
| Лист | Референс | Итог |
|---|---|---|
| `ryzhy_idle` | концепт | Персонаж стабилен; модель поставила кота «на задние лапы» в боксёрскую стойку; движение «дыхания» почти незаметно |
| `ryzhy_punch` | концепт | Хорошая фазовка удара, но стойка и масштаб отличаются от idle |
| `ryzhy_bite` | концепт | Самый выразительный клип; кот на четырёх лапах, в прыжке |
| `ryzhy_punch_v2` | кадр idle | **Стойка, масштаб и детали совпадают с idle** — переходы между клипами бесшовные |

`processed/compare_same_scale.png` — все клипы в одном масштабе (сверху вниз: idle, punch_v2, punch, bite).

## Выводы
- Внутри одного листа персонаж держится стабильно (морда, шрам, ухо, полоски, пропорции).
- Согласованность **между** клипами обеспечивается цепочкой референсов: канонический кадр idle → все остальные клипы.
- Хромакей и нарезка автоматизированы; чистка вручную не потребовалась.
- Стоимость: ~5 генераций ≈ $0.85 (вывод 5488 токенов на картинку 1536×1024 high + входная картинка).

## Исправление «скольжения ног» (2026-10-13)
**Проблема:** в idle ступни ездили влево-вправо на ~50 px. Причина — нарезка: кадр центрировался по своему прямоугольнику, а прямоугольник менялся при взмахах хвоста.

**Решение:** `sprite_process.py --anchor backfoot` (по умолчанию) — кадры выравниваются по опорной задней лапе (самая левая ступня, касающаяся земли; персонажи смотрят вправо). Ячейка симметрична вокруг этой точки, поэтому pivot спрайта (низ, центр) = опорная лапа. Для прыжков — `--anchor center`.

| | Разброс задней лапы по кадрам |
|---|---|
| До (центр прямоугольника) | 50 px (idle), 94 px (удар) |
| После (опорная лапа), в нарезке | ±0.5 px |
| После, на скриншотах Linux-билда | 1 экранный пиксель |

`processed/onion_idle8_before.png` / `onion_idle8_after.png` — все кадры наложены полупрозрачно, красная линия — pivot.

**Следствие для игры:** позиция персонажа = его опорная лапа, а не центр фигуры (учитывать при расстановке на арене).

## Масштаб и тряска idle (2026-10-13)
**Проблемы:** idle был на ~10% крупнее удара; голова в idle «прыгала» до 68 px по вертикали (промпт просил «пружинить», модель рисовала глубокие приседания).

**Решение:**
1. `ryzhy_idle8calm` — перегенерация от **первого кадра удара** (`ref_ryzhy_guard.png`) с промптом «ступни, голова и кулаки на месте, без приседаний». Тряска головы/корпуса: 68 px → 1 px.
2. `sprite_process.py --match-height 369` — клип масштабируется так, чтобы рост в стойке совпадал с эталоном (кадр 0 удара). На экране: idle 367–368 px, удар 367 px.
3. Модель не умеет «тонкое» движение (либо меняет позу целиком, либо ничего): кадры calm-idle почти идентичны. Жизнь добавлена кодом — `FlipbookClip.breathe` (плавное растяжение 1.2% вокруг опорной лапы, период 2.4 с). Голова ходит синусоидой на ~9 px, ступни неподвижны.

**Правило для конвейера:** эталон клипов персонажа — кадр 0 боевого удара; все клипы генерируются от него и масштабируются `--match-height` по его росту. Idle-циклы — спокойные кадры + процедурное дыхание.
