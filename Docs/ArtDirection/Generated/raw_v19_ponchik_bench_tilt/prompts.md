The arms keep their length and thickness (never stretched). The barbell is the same size in every frame, fully visible, the fists between the can bundles, it never covers the face. The SAME grumpy facial expression in all 8 frames. Comic book style exactly like the references. IMPORTANT: no bench, no floor line.
