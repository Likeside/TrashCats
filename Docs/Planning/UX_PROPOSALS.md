# Предложения по UX

Предложения, которые ещё не сделаны. Каждое берём в работу отдельно, после решения.

## Окно кота («Умения и статы»), 2026-10-14

Сейчас в окне: характеристики (иконка, уровень, полоска опыта), боевые статы иконками (HP, задор, урон), слоты умений с иконками, список умений с иконками, стоимостью в задоре и прогрессом до открытия закрытых.

1. **Описание у закрытых умений.** Сейчас у закрытого умения виден только прогресс («2/4 · нужно: Техника 4»), но не что оно делает — непонятно, ради чего качаться. Показывать описание и прогресс вместе (строка выше прогресса или мельче).
2. **Выбор умения из слота.** Нажатие на занятый слот сейчас только снимает умение. Лучше открывать список доступных умений для этого слота: заменить в одно касание.
3. **Листание котов в окне.** Стрелки влево/вправо (или свайп) — переключиться на другого кота, не выходя в убежище.
4. **«Тренировать» у характеристики.** Маленькая кнопка у каждой строки характеристики, которая сразу отправляет кота на её снаряд: Сила — штанга, Техника — банка, Выносливость — скакалка.
5. **Энергия и сытость в шапке.** Две короткие полоски рядом с именем: видно, готов ли кот к бою, без возврата к карточке.
6. **Сравнение с врагом.** Если окно открыто из подготовки к бою — рядом со статами кота показать статы ближайшего врага (зелёным, где кот сильнее, красным, где слабее).
7. **Подсказка про задор.** По нажатию на иконку задора — коротко: откуда берётся и на что тратится. То же для HP и урона: из какой характеристики считаются.
