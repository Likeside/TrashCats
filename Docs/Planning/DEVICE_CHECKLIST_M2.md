# Чек-лист проверки на устройстве — M2 (graybox убежища)

Сборка: `Unity -batchmode -quit -projectPath . -executeMethod TrashCats.Editor.BuildScript.BuildAndroid -logFile build.log`
→ `Builds/Android/TrashCats-dev.apk` (IL2CPP, ARM64, Development). Установка: `adb install -r Builds/Android/TrashCats-dev.apk`.

| # | Проверка | Ожидание | Результат |
|---|---|---|---|
| 1 | Первый запуск | Убежище с Рыжим, Еда 10, Хлам 0; портретная ориентация | |
| 2 | Вырезы/закруглённые углы | HUD и нижняя навигация не заходят под вырез и системные панели | |
| 3 | Тап по Рыжему → «Добыча еды» | Кот уходит к «Улице», прогресс-бар, через 20 с «+3 еды» | |
| 4 | Кормление из карточки | Сытость растёт, Еда уменьшается, кнопка показывает цену | |
| 5 | Тренировка Силы до 4 | Всплывает «+15 силы»; после уровня 4 умение Укус в слоте (видно в отладке/сохранении) | |
| 6 | Энергия < 20 | Кот останавливается с пузырём «Устал» | |
| 7 | Свернуть на 5+ мин, вернуться | Окно «Пока тебя не было» с итогами | |
| 8 | Убить процесс (свайп из недавних) и запустить | Прогресс сохранён, потеря ≤ ~5 с | |
| 9 | Кнопка «Назад» Android при открытом листе | Лист закрывается | |
| 10 | DBG → «Время ×20» | Циклы идут в 20 раз быстрее | |
| 11 | DBG → «Сбросить прогресс» | Новая игра | |
| 12 | Плавность | Нет заметных подтормаживаний при анимации котов | |
