# ArtSource — версии игровой графики

Все версии обработанных кадров хранятся здесь и **никогда не перезаписываются**: новая версия = новая папка `vN_<описание>`.
В игру (Assets/_Project/Art) копируется только текущая версия. Исходные листы от GPT лежат в `Docs/ArtDirection/Concepts/spritesheets/`.

## Рыжий
| Папка | Что это | Источник |
|---|---|---|
| `v1_idle8_bob` | idle 8 кадров, «пружинит», выравнивание по опорной лапе | `ryzhy_idle8.png` |
